# MatInvent

[MatInvent: Combining Diffusion Models with Reinforcement Learning for Crystal Invention](https://arxiv.org/abs/2503.09787)

## Abstract

MatInvent is a crystal generation framework that couples pretrained diffusion models (MatterGen or DiffCSP) with a reinforcement learning (RL) fine-tuning loop. Candidate crystals are generated by the diffusion backbone, scored by property calculators (band gap, formation energy, etc.), and used to fine-tune the generator via a reward-weighted diffusion loss. After several RL iterations, the generator produces novel stable crystals that match user-specified property targets.

---

## Model Description

### Overview

The framework operates in three alternating phases:

1. **Sample** -- The diffusion backbone generates a batch of crystal structures.
2. **Score** -- Property calculators (density, HHI, band gap, synthesizability, etc.) evaluate each structure; a scalar reward is computed from the multi-property profile.
3. **Fine-tune** -- The generator is updated with a reward-weighted diffusion loss plus a KL regularizer that prevents the agent from drifting too far from the pretrained prior.

After each iteration, high-reward structures are stored in a replay buffer and a long-term memory for diversity filtering.

### Key RL Parameters

| Parameter | Description |
|-----------|-------------|
| `rl_epoch` | Number of RL outer-loop iterations |
| `topk_ratio` | Fraction of top-scoring structures kept for fine-tuning per iteration |
| `sample_cfg.num_samples` | Number of structures generated per iteration |
| `finetune_cfg.lr` | Fine-tuning learning rate |
| `reward_cfg.prop_cfg` | List of target properties (name, direction, numeric range) |
| `replay_cfg.capacity` | Experience replay buffer capacity |
| `div_filter_cfg.method` | Diversity filter method (`composition` or `rmsd`) |

---

## Dataset Description

MatInvent reuses the same datasets as its backbone model. Refer to the MatterGen or DiffCSP README for dataset details:

- **MP-20**: 45,231 inorganic crystals (Materials Project subset) with up to 20 atoms per unit cell.

## Results

| Config | Backbone | Default Reward Target |
| --- | --- | --- |
| [matinvent_mattergen.yaml](matinvent_mattergen.yaml) | MatterGen | band_gap (ascending) |
| [matinvent_diffcsp.yaml](matinvent_diffcsp.yaml) | DiffCSP | formation_energy (descending) |

Both configuration files follow the same structure as standard training configs, with an additional `RL:` section.

## Command

### Training

```bash
# MatterGen backbone
python structure_generation/train.py -c structure_generation/configs/matinvent/matinvent_mattergen.yaml

# DiffCSP backbone
python structure_generation/train.py -c structure_generation/configs/matinvent/matinvent_diffcsp.yaml
```

### Sample

```bash
# Mode 1: with RL-fine-tuned checkpoint
python structure_generation/sample.py --config_path='structure_generation/configs/matinvent/matinvent_mattergen.yaml' --checkpoint_path='./output/matinvent_mattergen/models/final/model.pdparams' --save_path='result_matinvent_mattergen/' --mode='by_dataloader'

# Mode 2: with DiffCSP backbone
python structure_generation/sample.py --config_path='structure_generation/configs/matinvent/matinvent_diffcsp.yaml' --checkpoint_path='./output/matinvent_diffcsp/models/final/model.pdparams' --save_path='result_matinvent_diffcsp/' --mode='by_dataloader'
```
